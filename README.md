# mainlineNERD

Nattering Engineers' Ramblings, Distilled.

A planned Wayback-style archive for technical Matrix discussions: browse and
search history, cite stable events, and retrieve context through a thin
CLI/skill interface. Preserve observed versions, including pre-redaction
copies, rather than only the latest view. This preserves captured copies; it
does not reverse redactions in the source room.

Goals include transparent retention rules and responsible, self-service
expunges across our retained copies and derived data. Public access to withdrawn
content and the legal/removal policy remain unsettled; these are goals, not
implemented guarantees.

Status: feasibility research. No archive service or ongoing collection.
